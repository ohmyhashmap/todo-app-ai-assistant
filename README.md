# Aplikasi Web To-Do List Sederhana Berbantuan Generative AI

## Deskripsi

Aplikasi web sederhana untuk mencatat daftar tugas (to-do list) yang dibuat sebagai Tugas I mata kuliah Pengembangan Aplikasi Berbasis Web.

Aplikasi ini memanfaatkan Generative AI sebagai asisten pemrograman dalam proses perancangan, penulisan kode, evaluasi, dan perbaikan.

## Fitur

- Menambah tugas
- Menampilkan daftar tugas
- Menandai tugas selesai/belum selesai
- Menghapus tugas
- Filter tugas: semua, aktif, selesai
- Menyimpan data di localStorage

## Teknologi
